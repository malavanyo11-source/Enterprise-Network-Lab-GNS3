# 5. Skills Demonstrated

This project is designed to showcase a combination of technical skills that are directly relevant to networking, systems administration, and security roles.

## Networking

- Building and troubleshooting a network simulation environment from the ground up
- Configuring Cisco IOS devices for routing and switching
- VLAN design and inter-VLAN routing
- Understanding and applying enterprise network segmentation principles

## Security

- Firewall configuration and policy management (FortiGate)
- Security zone design
- Site-to-site VPN configuration
- Applying a "not all traffic should flow freely" mindset to network design

## Systems Administration

- Windows Server 2022 installation and configuration
- Active Directory Domain Services setup and management
- DNS and DHCP configuration and troubleshooting

## Virtualization and Infrastructure

- VMware Workstation setup and VM management
- Integrating a virtualization platform with a network simulation tool (GNS3 VM architecture)
- Diagnosing and resolving connectivity issues between a client application and a virtualized backend

## Documentation and Communication

- Writing clear, structured technical documentation
- Explaining design decisions and their business justification, not just describing configuration steps
- Maintaining a public, version-controlled record of an ongoing technical project (via GitHub)

## Certifications and Background

This project is being built alongside preparation for the CCNA certification, and draws on prior hands-on cybersecurity experience.
