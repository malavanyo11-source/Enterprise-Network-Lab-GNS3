# 1. Project Goal

Most networking education focuses on a single vendor — usually Cisco. That makes sense for certification exams like the CCNA, but it doesn't reflect how real enterprise networks are actually built.

In the real world, a company's infrastructure is rarely one vendor end to end. A typical mid-size or large business network might run:

- Cisco for core routing and switching
- Fortinet for firewalling and perimeter security
- Windows Server for identity, DNS, and DHCP services
- A mix of other vendors depending on procurement, cost, and legacy systems

This project exists to close that gap. Rather than only knowing one vendor's command syntax, the goal is to build a fully functional, multi-vendor enterprise network from scratch, entirely in a virtualized lab environment, to develop practical skills that go beyond certification theory.

## Why This Matters for My Career

I'm currently working toward my CCNA, alongside some hands-on cybersecurity experience. But certifications alone don't prove you can actually build something. This project is meant to be evidence — a portfolio piece that a hiring manager can look at and see real, working configurations, real design decisions, and real troubleshooting, not just an exam pass.

## The End Goal

By the end of this build, the lab will include:

- A routed and switched core network
- Firewall-secured network segments with defined security policies
- A Windows Server environment providing Active Directory, DNS, and DHCP
- Full documentation of the build process, configuration files, and lessons learned

This isn't a one-off exercise. It's the foundation of an ongoing portfolio that will keep growing as I learn more.
